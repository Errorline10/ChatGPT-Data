# Great Citadel Bootstrap v1

Load this folder as the active Citadel data source:

```text
/citadel/citadel-v1/
```

Required files:

- `citadel-v1-manifest.json`
- `codex/citadel-v1-codex-core.json`
- `rooms/citadel-v1-room-index.json`
- `maps/citadel-v1-map-core.json`
- `renders/citadel-v1-render-core.json`

Rules:

1. The Citadel is a personal knowledge palace.
2. Rooms should map to real-world things, tools, collections, or systems.
3. The Embassy Archive connects to the People Index.
4. When saving to GitHub, never overwrite published history.
5. Use the highest numbered visible `citadel-vN` folder when reloading.
6. Prefer clean JSON for data and Markdown for instructions.
7. Targeted regeneration is allowed for a single clearly named file.

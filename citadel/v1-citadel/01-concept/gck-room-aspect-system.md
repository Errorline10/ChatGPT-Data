# GCK Room Aspect System

## Core Idea

A major room may have multiple aspects.

An aspect is a transformed state of a room that changes the visible environment, available stations, objects, and interactions while preserving the underlying room identity.

The room remains the same room. The experience of the room changes.

## Purpose

The Room Aspect System allows the Great Knowledge Citadel to support expandable, gamified knowledge spaces without requiring every collection or experience to become a separate room.

## Core Rule

A room may have multiple aspects.

An aspect changes:

- Room appearance
- Available stations
- Visible objects
- Interactive mechanisms
- Knowledge collections
- Mood and presentation

The underlying room identity remains unchanged.

## Gamified Interaction

Room aspects should be activated through in-world mechanisms.

Possible mechanisms include:

- Aspect Dial
- Projection Lens
- Crystal Selector
- Rotating Pedestal
- Wall Sigil
- Cryptex
- Magic Console
- Projection Table

## Visual / Spatial Room Example

The Visual / Spatial Room is the template example for this system.

Default state:

- Visual studio
- General visual and spatial learning
- Images
- Models
- Maps
- Light-based displays

DVD Library Aspect:

When the DVD Library Aspect is activated, the Visual / Spatial Room magically transforms into a DVD Library instance.

The room may reveal:

- DVD shelves
- Viewing station
- Movie index
- Collection filters
- Media metadata
- Cozy screening-library atmosphere

## Example Aspect Structure

Visual / Spatial Room
- Default Aspect
- DVD Library Aspect
- Art Gallery Aspect
- Map Studio Aspect
- Cinema Aspect

## Design Principle

Major rooms become expandable containers.

Aspects become unlockable experiences.

This allows the Citadel to grow without creating cluttered or disconnected room structures.

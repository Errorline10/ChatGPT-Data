# Key Forge and Rune Gem Password System

## Purpose

The Key Forge turns password entry into an in-world interaction. Instead of typing on a keyboard, the user forges a key by assembling symbolic Rune Gems.

## Core Problem

A password may need to support printable ASCII characters.

Typical password-capable printable ASCII set:
- 26 lowercase letters
- 26 uppercase letters
- 10 digits
- 32 common symbols

Total: 94 characters

## Rune Gem Reduction

Instead of showing 94 separate characters, the system uses combinations.

8 Gem Shapes × 12 Gem Colors = 96 Rune Gems

This gives enough combinations to represent the 94 printable password characters, with 2 spare combinations available for special use.

## Interaction

The user stands at the alcove shelf with spectacles on and looks down at the Key Forge.

Possible actions:
1. Choose a gem shape
2. Choose a gem color
3. Place the Rune Gem into the key mold
4. Pull the forge lever
5. A key tooth, notch, or glowing mark is created

The password is still represented under the hood, but the player experiences it as forging a physical key.

## Mapping Principle

Character = Gem Shape × Gem Color

The user does not need to see ASCII. They interact with symbolic objects.

## Lore Interpretation

A password becomes a forged key. Each password character becomes a Rune Gem impression, a tooth cut, or an engraved luminous mark on the key.

# Key Forge / Rune Gem Password System

## Purpose

The Key Forge turns password entry into an in-world interaction.

Instead of a keyboard, the user stands at the alcove shelf wearing spectacles and looks down at a forge-like puzzle mechanism.

The user does not type a password.  
The user forges a key.

## Printable Password Character Target

Common password-capable printable ASCII without space:

- 26 lowercase letters
- 26 uppercase letters
- 10 digits
- 32 symbols

Total: 94 characters

## Rune Gem Reduction

8 Gem Shapes × 12 Gem Colors = 96 possible Rune Gems

This is enough to represent the 94 printable password characters, with 2 spare combinations available for future use.

## Interaction Loop

1. Select gem shape
2. Select gem color
3. Place Rune Gem into key mold
4. Pull forge lever
5. Key receives a tooth, notch, or glowing mark
6. Repeat for each password character
7. Completed sequence becomes the in-game key

## Mapping Principle

Character = Gem Shape × Gem Color

The user experiences symbolic objects.  
The application maps those combinations back to password characters.

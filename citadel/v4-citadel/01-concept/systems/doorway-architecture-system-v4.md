# Doorway Architecture System

## Standard Great Hall Doorway Pattern

Left Alcove = Hidden Knowledge  
Center Door = Room Identity  
Right Alcove = Active Specialization

This allows room state to be shown as architecture instead of menus.

## Left Alcove: Knowledge Vault

The left alcove looks decorative by default.

Possible decorative forms:
- Crystal lantern
- Sealed reliquary
- Ornate display case
- Lens pedestal

Hidden Information Mode:
- A Vaulted Key appears
- The key means deeper layers are available

The Vaulted Key can indicate:
- Hidden metadata
- Source material
- OCR layers
- Confidence analysis
- Notes
- Restricted or contextual details

## Center Door: Room Identity

The center door remains stable and identifies the room from the Great Hall.

## Right Alcove: Active Specialization

The right alcove shows the active subcategory or station. For the Visual Intelligence Room, this is a rotating holographic artifact.

## Reusable Rule

Every major Great Hall room may eventually use:

Left Alcove = hidden/deeper knowledge  
Center Door = room identity  
Right Alcove = active specialization

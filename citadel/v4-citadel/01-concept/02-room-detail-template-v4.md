# Room Detail Template

Each room should eventually include:

## Identity

- Room ID
- Room name
- Room type
- Parent/location relationship
- Purpose
- Mood

## Geometry

- Shape
- Door count
- Door directions
- Niches/alcoves
- Ceiling
- Floor
- Windows
- Centerpiece

## Compass

- North wall
- East wall
- South wall
- West wall
- Diagonal doors if present
- Camera-facing rules

## Rendering

- Canonical prompt
- Directional prompts
- Detail prompts
- Lighting
- Materials
- Key objects

## Interaction

- Stations
- Hidden information modes
- Keys
- Selectors
- Alcove behavior
- User actions

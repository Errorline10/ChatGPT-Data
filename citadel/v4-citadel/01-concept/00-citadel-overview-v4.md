# Citadel Overview

The Great Citadel of Knowledge is a JSON-first knowledge model that can be rendered by a JavaScript application.

## Core Rule

JSON is authoritative.  
Markdown explains it.  
The application renders it.

## Current Known Spaces

- Citadel Exterior
- Entry Hall
- Great Hall
- Small Library
- Small Bedroom
- Visual Intelligence Room

## Main Spatial Flow

Citadel Exterior  
→ Entry Hall  
→ Great Hall  
→ Specialized rooms

## Current Working Philosophy

The Citadel should feel like a real place, not a flat menu. Navigation is represented by architecture: doors, alcoves, niches, stations, plaques, symbols, lights, and artifacts.
